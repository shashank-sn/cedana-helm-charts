# Cedana Helm charts

Cedana is automated GPU checkpointing and migration infrastructure that increases the useful work your GPUs deliver.

This repo holds `cedana-helm`, the Helm chart that installs Cedana on Kubernetes. Its README, [cedana-helm/README.md](cedana-helm/README.md), has the install command, what the chart installs, the prerequisites, uninstall and the main configuration options, with links to the full reference. Artifact Hub and `helm show readme` display that file, so changes to the chart's documentation go there.

The chart is published at `oci://registry-1.docker.io/cedana/cedana-helm`.
